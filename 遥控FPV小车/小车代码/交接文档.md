## 3. 当前硬件状态

- ESP32-CAM 已插 MB 下载底板，Micro-USB 连电脑
- 设备管理器已识别 **USB Serial Port (COM3)**（驱动 OK）
- 主板未接任何杜邦线，电池未接（烧录不需要）
- ⚠️ 链路中串了一个 **USB 隔离器**（非必需）。若烧录报 `Failed to connect` / 找不到端口 / 红灯闪烁，第一排查动作：拔掉隔离器直连

```
信号线：GPIO12→ENA  GPIO13→IN1  GPIO15→IN2  GPIO14→ENB  GPIO2→IN3  GPIO4→IN4
```

## 5. 烧录步骤（照做即可）

1. VS Code 打开文件夹 `D:\PLC\小车`
2. 等 PlatformIO 首次初始化（会自动下载 espressif32 平台和工具链，几百 MB，耐心；下载失败换手机热点重试）
3. 底部状态栏点 **✓（Build）**：应看到 `SUCCESS`，固件约 1MB 以内
4. 点 **→（Upload）**：自动识别 COM3，esptool 输出 `Writing at ... 100%` 即成功（MB 底板自动进下载模式，无需手动跳线）
5. 点 **插头图标（Monitor）**（115200），按一下 ESP32-CAM 上的 RST（或拔插一次 USB），应看到：
   ```
   ===== FPV 四驱小车启动 =====
   摄像头 OK
   热点已启动: FPV-Car
   浏览器打开: http://192.168.4.1
   ===== 就绪 =====
   ```

## 7. 排错表

| 现象 | 原因 | 对策 |
|---|---|---|
| Build 卡住/下载失败 | 网络 | 换手机热点；重启 VS Code |
| 找不到 COM3 | 隔离器挡道 / 驱动 | 拔隔离器直连；设备管理器确认 |
| Upload 报 `Failed to connect to ESP32` | 自动下载失败 | 拔隔离器直连；关掉串口监视器再传 |
| 烧录后无热点 | 摄像头初始化失败（见串口 0x105）| 重新按压摄像头排线 |
| 网页打不开 | 设备连了别的 WiFi | 确认连的是 FPV-Car，不是家里路由器 |
