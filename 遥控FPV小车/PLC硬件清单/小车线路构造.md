# esp32-cam板子连接L298N电机模块

| ESP32-CAM | L298N 排针 | 功能                |
| --------- | ---------- | ------------------- |
| IO12      | ENA        | 左侧电机调速（PWM） |
| IO13      | IN1        | 左侧电机方向        |
| IO15      | IN2        | 左侧电机方向        |
| IO14      | ENB        | 右侧电机调速（PWM） |
| IO2       | IN3        | 右侧电机方向        |
| IO4       | IN4        | 右侧电机方向        |
| 5V        | 5V         | 。。。              |
| GND       | GND        | 。。。              |
