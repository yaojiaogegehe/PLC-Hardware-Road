### 懒人选项

淘宝搜 `ESP32-CAM 小车套件`，有底盘+L298N+主板打包好的套装（约 70~100 元），注意别买成"STM32 版"或纯底盘。

### 先检查已经有的东西

之前买的"USB 烧录隔离器"——看一下它有没有标 **TX / RX / 5V / GND** 的四个针脚：
- **有** → 它是 USB 转 TTL 下载器，可以用来刷 ESP32-CAM（但操作繁琐），仍建议买带 MB 下载板的套装；
- **没有**（只是一个两头都是 USB 口的小盒子）→ 它是隔离器，本项目用不上，MB 下载板套装**必买**。

## 三、改良版接线方案（配合我修改后的固件）

> ⚠️ 不要照原网页的接线图接——那是配合自制 PCB 的。我们的接线以这份为准：

**电源部分（最容易翻车）**

- 电池（2 节 18650，约 7.4V）→ L298N 的 `+12V` 和 `GND` 螺丝端子
- L298N 的 `+5V` 输出 → ESP32-CAM 的 `5V` 脚（L298N 板上的 5V 稳压给主板供电）
- L298N 的 `GND` 和 ESP32-CAM 的 `GND` 必须连通（共地）
- 电解电容正极接 ESP32-CAM `5V`，负极接 `GND`
- 电机左 → L298N `OUT1/OUT2`，电机右 → `OUT3/OUT4`

**信号部分（ESP32-CAM ↔ L298N，杜邦线）**

| ESP32-CAM 引脚 | L298N 引脚 | 作用 |
|---|---|---|
| GPIO12 | ENA（拔掉跳线帽） | 左电机调速 |
| GPIO13 | IN1 | 左电机方向 |
| GPIO15 | IN2 | 左电机方向 |
| GPIO14 | ENB（拔掉跳线帽） | 右电机调速 |
| GPIO2 | IN3 | 右电机方向 |
| GPIO16 | IN4 | 右电机方向 |
